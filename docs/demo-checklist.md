# เช็กลิสต์เดโมแจ้ง

เอกสารนี้ให้เจ้าของใช้ก่อนและระหว่างเดโมให้อาจารย์ดู (มือถือ Android จริง + เบราว์เซอร์เดสก์ท็อป) ข้อมูลทุกอย่างเป็นข้อมูลเดโม ไม่มีผู้ใช้จริง และแอปยังไม่เปิดสู่สาธารณะ (ยังไม่มีเบลอหน้า/ป้ายทะเบียน ห้ามพูดว่ารูปถูกเบลอ)

## ก่อนเดโม (ประมาณ 15 นาทีก่อนเริ่ม)

1. **เปิดเครื่องและสแต็ก**
   - ปิดโหมดประหยัดไฟของโน้ตบุ๊ก เสียบสายชาร์จ
   - เปิดตัวค้าง WSL ไว้ (ไม่งั้น WSL ดับเมื่อไม่มีโปรเซสผูก): `wsl -e bash -c "sleep 86400"` ทิ้งไว้ในหน้าต่างหนึ่ง
   - ใน WSL ที่ `/mnt/d/Project/Jaeng`: `export PATH="$HOME/.local/node/bin:$PATH"` แล้ว `bash scripts/dev-up.sh`
   - ตรวจ `http://localhost:8000/api/health` ได้ `{"ok":true,"db":true}`
   - ครั้งแรกหลังแก้ `docker-compose.yml` ให้รอ `web` ติดตั้งเสร็จ (log ขึ้น `Local: http://localhost:4200/`) แล้วค่อยเริ่ม
2. **รีเซ็ตข้อมูลเดโม** `bash scripts/reset-db.sh` (ได้เรื่องเดโม 40 เรื่อง ไม่ใช่ `supabase db reset`)
3. **เปิด Mailpit** `http://localhost:54324` ไว้แท็บหนึ่ง (รหัส OTP เข้าที่นี่)
4. **เครือข่าย** มือถือกับโน้ตบุ๊กอยู่ Wi-Fi เดียวกัน (LAN) หรือใช้ tunnel (`bash scripts/tunnel.sh` ถ้าจะใช้) ปิด VPN
5. **มือถือ**
   - ติดตั้ง APK ล่าสุด (`bash scripts/build-apk.sh`) ชาร์จแบตเกิน 60% ปิดโหมดประหยัดพลังงาน ปิดการหมุนจออัตโนมัติถ้าไม่ต้องการ
   - เปิดแอป → หน้าตั้งค่าเซิร์ฟเวอร์ → ใส่ที่อยู่ของโน้ตบุ๊ก (เช่น `http://192.168.x.x:8000`) แล้วกดทดสอบ ต้องผ่าน
   - อนุญาตตำแหน่งและกล้องไว้ล่วงหน้า
6. **ซ้อม 1 รอบ** ตามสคริปต์ด้านล่าง แล้วรีเซ็ตข้อมูลอีกครั้ง (`bash scripts/reset-db.sh`) ก่อนเริ่มจริง

## สคริปต์เดโม 7 ขั้น

| # | ทำอะไร | เห็นอะไร | แอนิเมชันที่ควรสังเกต |
|---|--------|----------|------------------------|
| 1 | เปิดแอป ปล่อยให้ intro เล่น | จุดแสงกลายเป็นลำแสง เขียนคำว่า "แจ้ง" แล้วตกลงเป็นแผนที่ประเทศไทยแบบของเล่น มีวงตัวเลขรวมเรื่อง | intro ลำแสง, วงตัวเลขเด้งเข้า |
| 2 | ซูมเข้าไปที่ถนน (ปุ่ม + หรือจีบนิ้ว) หรือแตะวงตัวเลข | แผนที่ของเล่นค่อยๆ กลายเป็นแผนที่ถนนจริง ลำแสงแยกเป็นเรื่องๆ มีวันที่ค้างบอก | เปลี่ยนแผนที่, ลำแสงโผล่ทีละอัน |
| 3 | ล็อกอินเป็น "ผู้แจ้ง" แล้วกด **แจ้ง**: ถ่าย/เลือกรูป → เลือกหมวด → ปักหมุด → ส่ง (3 แตะ) | แต่ละขั้นเลื่อนเข้าตามทิศ ติ๊กหมวดวาด 0.2 วินาทีแล้วไปต่อ หน้าส่งแล้ว: วงแหวนวาด ติ๊กวาด ลำแสงขึ้นพร้อมประกาย แล้วข้อความลอยขึ้น | ช่วงเด่นที่ 1 (ส่งสำเร็จ ~1.1 วินาที) |
| 4 | ล็อกอินเป็น "ผู้ดูแล" → หน้าผู้ดูแล → รอตรวจ → อนุมัติ → อนุมัติ ขึ้นแผนที่ | การ์ดขึ้นแผ่นสีพร้อมติ๊กและประกายแล้วพับหาย ตัวเลขนับงานค้างหมุนลง จากนั้นกลับแผนที่เห็นลำแสงของเรื่องใหม่ | อนุมัติ (ติ๊ก+ประกาย+พับ), ตัวเลขหมุน |
| 5 | ล็อกอินเป็น "เพื่อนบ้านอีกคน" เปิดเรื่องนั้น กด **เจอเหมือนกัน** | ติ๊กวาด วงแหวนปล่อย ประกายกระจาย ตัวเลขหมุนเป็น 1 และดิสก์บนแผนที่กระเด้ง แท่งยืดขึ้น | ช่วงเด่นที่ 2 (ลำแสงเปลี่ยนสถานะ) |
| 6 | กด **แจ้งว่าแก้แล้ว** → ส่ง แล้วให้ผู้ดูแลยืนยันในแท็บ "แจ้งว่าแก้แล้ว" | หลังส่ง ลำแสงหรี่ลง (claimed) หลังผู้ดูแลยืนยัน ลำแสงกะพริบสองครั้งแล้วดับ เหลือเครื่องหมายถูก | หรี่ → กะพริบดับ |
| 7 | สลับภาษาเป็น English แล้วกลับไทย (บนมือถือ: หน้า "เกี่ยวกับ" → การตั้งค่าภาษา; บนเดสก์ท็อป: ปุ่ม EN/ไทย บนแผนที่) | คำทั้งหน้าเปลี่ยนด้วยการเฟด ธีมสว่าง/มืดสลับด้วยวงกลมกางจากปุ่มที่กด | เฟดภาษา, วงกลมธีม |

พูดประกอบ (ขั้นละ 1–2 บรรทัด): ปัญหาในชุมชนกลายเป็นลำแสงบนแผนที่ → แจ้งใน 3 แตะ → ผู้ดูแลตรวจก่อนขึ้นแผนที่ → เพื่อนบ้านกด "เจอเหมือนกัน" ลำแสงสูงขึ้น → แจ้งว่าแก้แล้ว ลำแสงหรี่ → ผู้ดูแลยืนยัน ลำแสงดับ ปัญหาที่ยังไม่แก้ยังเห็นว่าค้างมากี่วัน

## ถ้าพัง ทำอย่างไร

| อาการ | ทำอย่างนี้ |
|-------|-----------|
| อินเทอร์เน็ตหลุด | แอปใช้ LAN กับโน้ตบุ๊กได้โดยไม่ต้องมีอินเทอร์เน็ต ยกเว้นไทล์แผนที่ถนนจริงตอนซูมใกล้ (แผนที่ของเล่นยังใช้ได้) เดโมต่อด้วยมุมซูมไกล |
| GPS ไม่ขึ้น / ปักหมุดไม่ได้ | ปุ่ม "แจ้ง" ยังใช้ได้: ซูมเข้าจนถึงระดับถนน (ซูม 14+) แล้วลากหมุดเอง ปุ่มส่งจะเปิดเมื่อซูมพอ |
| OTP ไม่มา | เปิด Mailpit `:54324` ดูรหัสเอง หรือใช้ปุ่ม "สลับผู้ใช้สำหรับเดโม" ในแผ่นล็อกอิน (ใช้ได้เฉพาะ localhost / ที่อยู่เซิร์ฟเวอร์ที่ตั้งไว้) |
| ไฟล์ใหญ่ / รูปอัปโหลดไม่ผ่าน | แอปบีบรูปให้เองจนไม่เกิน 3 MB; ถ้ายังไม่ผ่านให้เลือกรูปอื่น ปุ่ม "ลองใหม่" บนรูปที่ล้ม |
| แอปค้าง / เซิร์ฟเวอร์ตอบช้า | `bash scripts/dev-down.sh && bash scripts/dev-up.sh` แล้วรีเฟรช (ข้อมูลเดโมไม่หาย ถ้าต้องการเริ่มใหม่ `bash scripts/reset-db.sh`) |
| ลำแสงไม่ขยับตามที่กด (ไม่เห็นเรียลไทม์) | รีเฟรชหน้า ลำแสงโหลดใหม่จากฐานข้อมูล |
| แท็บเบราว์เซอร์แอนิเมชันค้าง | แอนิเมชันหยุดเมื่อแท็บถูกซ่อน ให้เปิดแท็บให้อยู่หน้าสุด |
