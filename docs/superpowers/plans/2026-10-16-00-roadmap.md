## งานที่ยกมาจากแผน 1 (ผลการตรวจทั้ง branch)

แผนถัดไปที่ระบุไว้ต้องนำข้อเหล่านี้ไปทำด้วย:

- ~~**แผน 2:** `dark.system.css` ของ Ionic ทับ token สีในโหมดมืด~~ แก้แล้วในแผน 2 (เลิกโหลด dark palette ของ Ionic ให้ token เป็นแหล่งสีเดียว)
- **แผน 3:**
  - แทนการ์ด peek ด้วยแผงรายละเอียด และให้ `BeaconLayer` รับ id ของเรื่องที่เลือก เพื่อคงวงสีน้ำเงินไว้เมื่อ marker ถูกสร้างใหม่ และคืนโฟกัสให้ถูก
  - หน้าแผนที่จะมีหน้าอื่นข้างๆ แล้ว ให้ทดสอบว่าออกจากหน้าแผนที่แล้วไม่มี WebGL context ค้าง (มี guard แล้วใน `MapPage`)
  - ผู้แจ้งที่ปิดชื่อแล้วไปคอมเมนต์เรื่องของตัวเองจะเห็นชื่อในความคิดเห็น ให้พิจารณาซ่อนชื่อในกรณีนี้
  - ตรวจ JWT แบบ HS256 หรือแบบ JWKS
  - ผู้ใช้ที่ถูกแบนต้องเขียนข้อมูลผ่าน API ไม่ได้
- **แผน 4:**
  - ลบแถว `report_photos` ที่ไม่ได้ผูกกับเรื่องไหน
  - ค้นแท็กแบบ substring และ escape `%` กับ `_` ใน `q`
  - ห้าม `tags.name` ขึ้นต้นด้วย `#`
  - ให้ `place_name` คำนวณจาก `public_location`
- **แผน 5:** ข้อมูลเดโมที่สถานะ `fix_claimed` ต้องมีแถว `fix_claims` ที่ pending ด้วย
- **แผน 6** (จากรีวิวแผน 2):
  - ช่วง zoom ~7 ภาพประกอบผสมกับแผนที่ปกติแบบ alpha ตรงๆ ดูเป็นสีเขียวขี้ม้า ควรทำให้ดูเหมือน "ฟ้าแจ้ง" (เช่น ค่อยๆ ไล่เป็นสีพาสเทลหรือใช้เมฆบัง)
  - ซ่อนป้ายชื่อเมืองของ positron ที่ zoom < 7.5 และตามธีมมืดของแผนที่พื้นฐาน (ตอนนี้ positron ยังเป็นสีสว่าง และ `--sea` อ่านครั้งเดียวตอนโหลด)
  - วงตัวเลขบอกได้แค่ระดับสูงสุด ควรพิจารณาบอกสัดส่วนระดับ (เช่น จำนวนเรื่องวิกฤต) ตามที่ critique เสนอ
  - ปุ่ม "กลับไปดูทั้งประเทศ" และ toast ที่มีปุ่มลองใหม่
  - ป้ายจังหวัดบนมือถือ: สงขลายังอยู่ใต้ปัตตานีเมื่อวงตัวเลขทับ, ไอคอน 🛕 (เจ้าของเลือกเองในหัวข้อ 3.2.1) ดูเป็นวัดฮินดูมากกว่าวัดไทย ให้เจ้าของตัดสินว่าจะเปลี่ยนเป็นภาพวาดเองไหม
- **แผน 6:**
  - `resolved_this_month` ต้องใช้เดือนตามเวลาไทย (Asia/Bangkok)
  - เพิ่มทางดูเรื่องที่แก้แล้วเกิน 30 วันใน `/list`
- **แผน 8:**
  - จัดวาง UI ของหน้าใหม่ทั้งหมด (เจ้าของสั่ง 2026-10-17 ให้ทำหลังระบบเสร็จ)
  - pin `nodemon` เป็น devDependency
  - อย่าให้ `npm ci` รันทุกครั้งที่สตาร์ต container
- **แผน 10:**
  - Caddy เปิด Kong ทั้งหมดบน 0.0.0.0:8000
  - helper `tests.create_user` ต้องไม่ไปถึงฐานข้อมูลจริง
