# แจ้ง — Plan 1: Foundation (dev environment + database) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring up the full local stack (Supabase + Elysia API + Angular/Ionic web behind Caddy on `localhost:8000`) in Docker on WSL. Ship the complete database: schema, public views and functions, RLS and storage buckets, with demo seed data and passing pgTAP tests.

**Architecture:** The Supabase CLI runs Postgres, Auth, Storage, Realtime and Studio in Docker. `docker-compose.yml` runs `caddy`, `api` and `web` on the Supabase network. Caddy is the single origin: `/` goes to web, `/api/*` to api (prefix stripped) and `/sb/*` to Kong (prefix stripped). The browser reads through public views and functions only. All writes go through the API (later plans).

**Tech Stack:** WSL2 Ubuntu 26.04, Docker 29 + Compose v2, Supabase CLI (via `npx supabase`), Postgres + PostGIS + pg_trgm, pgTAP, Bun + Elysia, Angular + Ionic 8, Caddy 2.

**Spec:** `docs/superpowers/specs/2026-10-16-jaeng-design.md` (sections 4, 5, 6, 8). Roadmap: `docs/superpowers/plans/2026-10-16-00-roadmap.md`.

## Global Constraints

- Run every command inside WSL (`wsl` → `cd /mnt/d/Project/Jaeng`). Never use the host's Windows Node for project scripts.
- Ports: Caddy `8000`; Supabase API `54321`, DB `54322`, Studio `54323`, Mailpit `54324`. Never bind `8080` (used by `docker-webui/`).
- Supabase `project_id = "jaeng"`, so the network is `supabase_network_jaeng` and Kong is `supabase_kong_jaeng:8000`.
- Danger levels are exactly `0..3`. Statuses are exactly `pending_review, open, fix_claimed, resolved, rejected, hidden`.
- Never commit `.env`. Read all keys from `npx supabase status -o env` and never hardcode them.
- Category seed (slug, name_th, name_en, icon, default_level, sort) exactly: `road, ถนน/ทางเท้า, Road & sidewalk, 🕳️, 1, 1` · `light, ไฟฟ้า/ไฟส่องสว่าง, Lighting & power, 💡, 1, 2` · `water, น้ำประปา/ท่อระบาย, Water & drains, 💧, 1, 3` · `flood, น้ำท่วม, Flooding, 🌊, 2, 4` · `waste, ขยะ, Waste, 🗑️, 0, 5` · `tree, ต้นไม้, Trees, 🌳, 1, 6` · `hazard, จุดเสี่ยง/ความปลอดภัย, Safety hazard, ⚠️, 2, 7` · `other, อื่นๆ, Other, 📍, 0, 8`.
- Level constants exactly: `0 ทั่วไป/Minor #8FD3B6 ● 3s` · `1 ควรระวัง/Caution #F6D983 ▲ 2.4s` · `2 อันตราย/Danger #F4A582 ◆ 1.6s` · `3 วิกฤต/Critical #E57373 ⚠ 1s`.
- Beam height: `min(260, 60 + 36 * log2(1 + n))` px, rounded to an integer.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Branch `master`, remote `origin` = `https://github.com/BKungBK/Jaeng.git`.

## Review Focus

1. **Thai search text.** `reports_in_bbox(..., q => 'หลุม')` must match titles and tags that contain Thai substrings. The test lives in Task 9.
2. **A point outside any district** (sea, or outside Thailand). `area_name_at` returns `null` and does not error. The test lives in Task 7.
3. **A hidden author leaking through public reads.** `public_reports.author_name` is null when `hide_author`, and no public view exposes `author_id` or the true `location`. The tests live in Tasks 9 and 10.
4. **Privilege escalation through a profile update.** An authenticated user updating their own `role` to `admin` is rejected. The test lives in Task 10.
5. **A double "me too", or a me-too and un-me-too race.** A duplicate `(report_id, user_id)` is rejected, and `confirm_count` always equals the row count. The test lives in Task 8.
