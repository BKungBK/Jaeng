# แจ้ง — Plan 2: Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the blank home page with the real map: a MapLibre v5 globe masked to Thailand, a toy-like illustrated Thailand that fades into the OpenFreeMap street map between zoom 6 and 8, density clusters, Bat-Signal beacons (HTML markers) sized by `beamHeight`, a hover tooltip, a tap/click peek card and four level filter chips, all fed by `reports_in_bbox` from the real database.

**Architecture:** One `MapPage` at `/` owns a single MapLibre map. Pure modules (`report.ts`, `beacon.ts`, `toy.ts`) hold every rule that can be unit-tested in jsdom; thin classes (`BeaconLayer`, `ToyOverlay`) bind those rules to the map. Toy land, mask and landmark icons are MapLibre layers; Thai province labels, moving objects and beacons are HTML markers (MapLibre's glyph renderer misplaces Thai vowel and tone marks). Data comes from `supabase.rpc('reports_in_bbox')` through `ReportsService`, with a latest-request-wins loader.

**Tech Stack:** Angular 22 + Ionic 9 (standalone, signals, zoneless), MapLibre GL JS 5.24.0, @supabase/supabase-js 2.118.0, OpenFreeMap `positron`, OCHA COD-AB geometry, Microsoft Fluent Emoji 3D (MIT), mapshaper 0.7.87, Vitest (Angular unit-test builder).

**Spec:** `docs/superpowers/specs/2026-10-16-jaeng-design.md` (3.2, 3.2.1, 3.3, 3.4, 3.11, 3.11.1, 3.13, 4.4, 7.1, 7.2). Design system: `DESIGN.md` + `.impeccable/design.json`. Surface brief with direction contract: `.impeccable/surfaces/apps-web-src-app-features-map-map-page-ts.md`. Prototype: `docs/prototype/thai-map-v2.html`.

## Review Focus

1. **Out-of-order responses while panning fast.** An older `reports_in_bbox` call that resolves after a newer one must be dropped. Test in Task 3 (`ReportsLoader`).
2. **All four chips switched off.** No RPC is sent, the map clears, and the hint says nothing matches. Tests in Task 3 (`ReportsService`) and Task 4 (`zoomHint`).
3. **Globe-view bounds.** At zoom ≤ 3 `getBounds()` can exceed ±180 / ±85 or wrap the antimeridian; the bbox sent must be clamped to `[-180,-85,180,85]`. Test in Task 3 (`toBbox`).
4. **RPC or network failure.** The previous beacons stay, a toast says the load failed, nothing throws. Test in Task 3 (`ReportsService` rejects → loader returns `{ error }`).
5. **Hostile or overlong titles.** A title such as `<img src=x onerror=alert(1)>` renders as text, and a 120-character Thai title is ellipsised in the label pill and wraps in the tooltip. Test in Task 5 (`createBeaconElement`).
