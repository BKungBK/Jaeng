- แผ่นดิน: เลเยอร์ vector เดิม เปลี่ยนเป็นสีทึบ 3 โทนต่อภาค, เส้นขอบหมึก และชั้นดินที่ยกนูน ช่วงซูมสูง positron ถูกย้อมเป็นโทน cel เดียวกัน
- เฉพาะไทย: เลิกใช้ globe และใช้ mercator พร้อม `maxBounds` กับ `minZoom` หน้ากากทึบตลอดทุกซูม สิ่งที่อยู่นอกไทยจึงเห็นเป็นทะเลอย่างเดียว

## จุดที่ต้องตรวจเป็นพิเศษ

1. **ขอบฝั่งที่ zoom 14+:** ทะเลต้องไม่ล้นทับถนนริมชายฝั่ง (เช่น หาดพัทยา หรือป่าตอง) และต้องไม่เว้นช่องว่างระหว่างทะเลกับฝั่ง
2. **ประสิทธิภาพ:** บนมือถือระดับกลาง (Chrome DevTools CPU 4× slowdown) ต้องได้ ≥ 30 fps ตอนลากแผนที่ ส่วน shader จำกัดการวาดไว้ที่ 30 fps เมื่อแผนที่อยู่นิ่ง
3. **WebGL context:** ออกจากหน้าแผนที่แล้วต้องไม่มี buffer หรือ texture ค้าง (`onRemove` ลบครบ)
4. **ธีมมืด:** สลับธีมระหว่างใช้งานแล้วสีทะเลกับแผ่นดินต้องเปลี่ยนตาม (แก้ข้อค้างจากแผน 2 ที่อ่าน `--sea` ครั้งเดียว)
5. **ลากออกนอกไทย:** ลากหรือซูมยังไงก็ต้องไม่เห็นแผ่นดินประเทศอื่นหรือป้ายชื่อของ positron นอกไทย

### Task 7: ทะเล cel-shading (custom WebGL layer)

**Files:** Create `features/map/sea/sea-layer.ts`, `sea.glsl.ts`, `sea-palette.ts`, `sea-geometry.ts`, `sea-clock.ts` และ spec ของ `palette`, `geometry`, `clock`

**Interfaces:**
```ts
export function seaTriangles(mask: FeatureCollection): { positions: Float32Array; indices: Uint32Array }; // earcut ในพิกัด mercator 0..1
export function seaPalette(theme: 'light' | 'dark'): SeaPalette; // deep, mid, shallow, foam, caustic, sparkle เป็น vec3
export class SeaClock { constructor(reducedMotion: boolean); now(): number; shouldRepaint(): boolean } // จำกัด 30 fps, หยุดเมื่อ hidden
export class SeaLayer implements maplibregl.CustomLayerInterface { id = 'sea'; type = 'custom'; renderingMode = '2d'; ... }
```

**Shader (fragment) ทำงานตามลำดับนี้:**
1. `d = texture(sdf, uv).r` → แบ่งความลึกเป็นแถบสีทึบ 3 ขั้นด้วย `step` ไม่ไล่เฉด ได้แก่ `shallow` (ฟ้าอมเขียว `#3FD6C8`), `mid` (`#1FA2E0`) และ `deep` (`#1556B8`) ขอบแถบบิดเล็กน้อยด้วย noise ช่อง G และเวลา ให้เส้นแบ่งความลึกดูเหมือนน้ำไหว
2. **Caustics:** ทำเฉพาะแถบ shallow และ mid โดยใช้ Voronoi 2 ชั้นที่เลื่อนสวนทางกัน แล้ว `smoothstep` ให้แคบลงเป็นเส้นแสงสีอ่อน ความเข้มลดลงตาม `d`
3. **ฟองชายฝั่ง:** แถบขาว `d < foamWidth` ที่หนาบางตาม `sin(time*1.2 - d*k)` ให้ดูเหมือนคลื่นซัดเข้าออก และมีเส้นฟองบางอีกเส้นตามหลังห่างออกไป
4. **แสงระยิบ:** จุด hash ที่กะพริบเป็นช่วงสั้น เกิดเฉพาะแถบ mid และ deep
5. ความกว้างของฟองและขนาดลายคิดเป็นพิกเซลจอผ่าน uniform `pxPerUnit` (จาก zoom) ลายจึงไม่หนาเกินตอนซูมเข้าและไม่หายตอนซูมออก

**Steps:**
- [ ] **Step 1: Tests (jsdom):** `seaTriangles(mask)` ได้สามเหลี่ยม > 0 และทุกจุดอยู่ใน 0..1, `seaPalette('dark')` เข้มกว่า light ทุกช่อง, `SeaClock` ที่เป็น reduced motion คืนเวลาคงที่และ `shouldRepaint()` เป็นเท็จ, และ `SeaClock` จำกัด repaint ไว้ที่ ≥ 33 ms ต่อเฟรม
