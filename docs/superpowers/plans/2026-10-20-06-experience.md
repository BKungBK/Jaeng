## การตัดสินใจที่ผู้เขียนแผนเลือกเอง (เจ้าของค้านได้ก่อนลงมือ)

1. **ไม่ใช้ Transloco** (สเปก 4.2 เขียนไว้ แต่ไม่ได้มาร์ก **ตัดสินแล้ว**) เขียน `I18nService` + pipe เองราว 100 บรรทัด เพราะ: (ก) ไม่ต้องดาวน์โหลดแพ็กเกจ และไม่เสี่ยงเรื่อง peer dependency กับ Angular 22 ที่ยังไม่มีใครยืนยัน (ข) คีย์มีชนิด: พิมพ์คีย์ผิดหรือแปลไม่ครบเป็น compile error ไม่ใช่ข้อความหายตอนเดโม (ค) signal ทำงานกับ zoneless + OnPush ตรงๆ ราคาที่จ่าย: ไม่มีเครื่องมือของ Transloco (scope, lazy load ต่อภาษา, plural แบบ ICU) — แอปนี้มีสองภาษาและข้อความราว 400 ข้อ พจนานุกรมทั้งคู่จึงรวมใน bundle ได้ (ราว 30 KB ก่อนบีบอัด) แก้สเปก 4.2 ตอนปิดงาน
2. **ภาษาเริ่มต้นคือไทยเสมอ** ไม่อ่าน `navigator.language` (สเปก 3.12) ลำดับ: ค่าที่เลือกไว้ในเครื่อง (`localStorage['jaeng.locale']`) → `profiles.locale` ของผู้ที่ล็อกอิน (ใช้เมื่อเครื่องนี้ยังไม่เคยเลือก) → `th` · เปลี่ยนภาษาขณะล็อกอินอยู่ → `PATCH /api/me {locale}` แบบไม่รอ (ล้มเหลวแค่ log)
3. **ธีมเก็บในเครื่องอย่างเดียว** (`localStorage['jaeng.theme']`: `system` | `light` | `dark`, ค่าเริ่มต้น `system`) ไม่บันทึกที่เซิร์ฟเวอร์ เพราะเครื่องต่างกันมักอยากได้ธีมต่างกัน
4. **ปุ่มภาษาอยู่ในการ์ดแบรนด์** (ข้อความ "EN" / "ไทย") เพราะฉากเดโมสลับภาษาตอนยังไม่ล็อกอิน และเมนูบัญชีมีเฉพาะคนที่ล็อกอิน ส่วนการเลือกธีมอยู่ที่ `/me` และ `/about` (ส่วน "การแสดงผล" ที่ทุกคนเข้าได้) ตาม handoff
5. **ข้อความผิดพลาดตามภาษา:** `ApiError` ถือทั้ง `messageTh` และ `messageEn` (API ส่ง `message_en` มาอยู่แล้ว) ข้อความที่เว็บสร้างเอง (`network`, 413, ไม่มี token) มาจากพจนานุกรมทั้งสองภาษา ทุกที่ที่เคยแสดง `e.messageTh` เปลี่ยนเป็น `i18n.errorText(e)`
6. **`public_reports` รวมเรื่องที่แก้แล้วทุกอายุ** แทนการสร้าง view ที่สอง เงื่อนไข "หายจากแผนที่หลัง 30 วัน" ย้ายไปอยู่ใน `reports_in_bbox` ผลพลอยได้: ลิงก์ `/r/:id` ของเรื่องเก่าที่แก้แล้วยังเปิดได้ (สเปก 3.3 "ยังค้นเจอในรายการ") ราคาที่จ่าย: เรื่องเก่าที่แก้แล้วรับความคิดเห็นและรายงานได้เหมือนเรื่องที่แก้ไม่เกิน 30 วัน (`toggle_confirmation` ปฏิเสธเรื่อง `resolved` อยู่แล้ว)
7. **ค้นหาเป็นรายการให้เลือก ไม่ใช่ตัวกรองค้างบนแผนที่:** พิมพ์ ≥ 2 ตัวอักษร → ผลสองกลุ่ม "สถานที่" (บินไป) และ "เรื่อง" (เปิด `/r/:id`) กลุ่มละไม่เกิน 5 เรื่องค้นทั้งประเทศด้วย `reports_in_bbox(THAILAND_BBOX, q)` ที่มีอยู่แล้ว ไม่เพิ่ม endpoint ค้นเรื่อง
8. **`GET /places`:** เปิดให้ทุกคน (อ่านอย่างเดียว) ผลในเครื่องมาก่อนเสมอ แล้วต่อด้วย Nominatim (`countrycodes=th`, `accept-language`, `limit=5`) ตัดผลที่ชื่อซ้ำกับผลในเครื่อง ต้นทางถูกเรียกไม่เกิน 1 ครั้งต่อวินาทีทั้งเซิร์ฟเวอร์ (คิวเดียว) ตามกติกาของ Nominatim, User-Agent `Jaeng/0.6 (+<NOMINATIM_CONTACT>)` โดยค่าเริ่มต้นของ contact คือ URL ของ repo (ไม่ใส่อีเมลใคร) · ตอบ `{ places, online: boolean }` โดย `online:false` เมื่อต้นทางล่ม/ช้า/ตอบผิดรูป
9. **ตัวเลขกำลังใจอยู่ในการ์ดแถบสถานะเดิม** (บรรทัดบนของการ์ดมุมล่างซ้าย) ไม่เพิ่มการ์ดที่สองบนจอ 375 px · ล้มเหลวแล้วซ่อนบรรทัดนี้เงียบๆ (เป็นกำลังใจ ไม่ใช่ข้อมูลที่ต้องใช้)
10. **วงตัวเลข:** นอกจากขอบสีของระดับสูงสุด ถ้ามีเรื่องวิกฤตในกลุ่มให้มีป้ายเล็ก "รูปทรงวิกฤต + จำนวน" (ข้อเสนอจาก critique ของแผน 2) ใช้ `clusterProperties.critical` ของ MapLibre ไม่ทำสัดส่วนทุกระดับ เพราะวงเล็ก 52 px อ่านไม่ออก
11. **ป้ายชื่อบนแผนที่ถนนตามภาษา:** symbol layer ของ positron เปลี่ยน `text-field` เป็น `coalesce(name:th|name:en, name)` เมื่อสลับภาษา
12. **PWA เสิร์ฟที่ `http://localhost:8100`** (site ที่สองของ Caddy ที่เสิร์ฟ `apps/web/www` และ proxy `/api`, `/sb` เหมือน 8000) เพราะ service worker ทำงานเฉพาะ production build (สเปก 4.2) และ dev server ที่ 8000 ต้องคงไว้สำหรับพัฒนา · ไอคอนแอปวาดด้วยสคริปต์ (`pngjs` ที่เป็น devDependency อยู่แล้ว) ไม่ดาวน์โหลดภาพ แผน 7 ใช้ไฟล์เดียวกันได้
13. **ดาวน์โหลดที่ต้องได้รับอนุญาต:** แผนนี้ต้องติดตั้ง `@angular/service-worker@22.1.7` (แพ็กเกจของ Angular เวอร์ชันเดียวกับ core) และ API เรียก Nominatim ตอนรัน **การอนุมัติแผนนี้ถือเป็นการอนุญาตทั้งสองอย่าง** ถ้าไม่อนุญาต Task 12 จะเหลือแค่ manifest + ไอคอน (ติดตั้งได้แต่ไม่ทำงานออฟไลน์) และ `/places` ตอบแค่ผลในเครื่อง
14. **ซูมหน้าได้:** เอา `maximum-scale=1, user-scalable=no` ออกจาก `index.html` (WCAG 1.4.4) แผนที่ยังจับ pinch เองผ่าน `touch-action` ของ MapLibre
