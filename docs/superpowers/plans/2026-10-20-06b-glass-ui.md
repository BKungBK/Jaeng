**เป้าหมาย:** เปลี่ยนหน้าตาทั้งแอปเป็นกระจกฝ้ามี noise บนพื้นกราเดียนต์กลางคืนสู่รุ่งเช้า จัดหน้าแผนที่ใหม่ให้โล่งตามภาพร่างที่เจ้าของอนุมัติ (`.impeccable/mocks/decision/fused-mobile.html`, `fused-desktop.html`) เพิ่มอนิเมชันตอนเปิดแอป การเปลี่ยนหน้า การบินกล้อง และพื้นหลังแบบ shader **โดยพฤติกรรมเดิมทุกอย่างยังทำงานและเทสต์เดิมยังผ่าน**

**ไม่อยู่ในแผนนี้:** เปลี่ยนข้อมูลหรือ API · เปลี่ยนรูปทรง beacon/cluster (แค่ปรับวัสดุ) · ภาพประกอบแผนที่แบบของเล่น ทะเล shader ที่มีอยู่ และสีภาค (เจ้าของบอกว่าชอบแผนที่แบบเดิม) · Capacitor (แผน 7) · ลาก bottom sheet สรุปขึ้นเป็นรายการ (แถบสรุปกดแล้วไป `/list` แทน)

**สถาปัตยกรรม:**
- **วัสดุเดียวทั้งแอป:** ไฟล์ใหม่ `theme/glass.scss` นิยามตัวแปร (`--glass-*`, `--noise`, `--dawn`) และคลาส global `.glass` ทุกแผงใช้คลาสนี้ ไม่มีใครเขียน `backdrop-filter` เอง ธีมสว่างใช้คลาสเดียวกันแต่ค่าตัวแปรเป็นกระจกขาว
- **หน้าแผนที่:** โครง DOM แยกตาม `wide()` ที่มีอยู่แล้ว (820 px) จอกว้างได้แผงซ้าย (`aside.side`) แคปซูลเมนู (`nav.menu`) แท่งควบคุม (`.controls`) และปุ่ม "+ แจ้ง" ส่วนมือถือได้แถบค้นหา (`header.bar`) แถวชิป แถบสรุป (`.summary`) ปุ่มตำแหน่ง และ Dock (`nav.dock`) logic ใน `MapPage` เพิ่มแค่ `inView` (3 เรื่องเด่นในจอ) และ `hintIsState`
- **อนิเมชัน:** ค่าเวลาและ easing อยู่ที่เดียวคือ `core/motion.ts` · การเปลี่ยนหน้าใช้ `[animation]` ของ `ion-router-outlet` · intro เป็น component เดียวใน `app.component.html` · พื้นหลัง shader เป็น component เดียว (`app-backdrop`) ที่ถอยไปใช้ CSS gradient เมื่อไม่มี WebGL

## การตัดสินใจที่ผู้เขียนแผนเลือกเอง (เจ้าของค้านได้ก่อนลงมือ)

1. **ชื่อแผน 6b** เพื่อไม่ต้องเลื่อนเลขแผน 7 (APK) ที่ roadmap อ้างไว้หลายที่ งาน "จัดวาง UI ของหน้าใหม่ทั้งหมด" ใน roadmap แผน 8 ย้ายมาอยู่แผนนี้
2. **ธีมมืดเป็นค่าเริ่มต้น** เมื่อเครื่องยังไม่เคยเลือก (เดิมคือตามเครื่อง) ตัวเลือก "ตามเครื่อง" ยังมีใน `/me` และ `/about` ธีมสว่างยังอยู่ ใช้โครงเดียวกันแต่เป็นกระจกขาว
3. **ฟอนต์ Anuphan ทั้งแอป** แทน Prompt + IBM Plex Sans Thai (ดูทันสมัยกว่าและมีน้ำหนัก 300–600 ครบ) ยกเว้นฟอนต์ glyph ของ MapLibre (`text-font` ใน `map-style.ts`) ที่เป็นไฟล์ PBF ฝั่งเซิร์ฟเวอร์ ไม่แตะ
4. **สีหลักโหมดมืด `--pri` = `#F4B49A` (พีช)** และ `--onpri` = `#2A1F3A` เพราะสีฟ้าเดิมชนกับทะเลกราเดียนต์ กราเดียนต์รุ่งอรุณเต็มๆ ใช้แค่ 3 ที่: โลโก้ ปุ่มแจ้ง และวงแหวนสถิติ
5. **มือถือไม่มีปุ่มซูม** (ใช้นิ้ว) ปุ่ม "กลับไปดูทั้งประเทศ" ย้ายไปเป็นแท็บ "แผนที่" ใน Dock (แตะแท็บที่อยู่แล้ว = กลับไปดูทั้งประเทศ แบบแอปทั่วไป) ภาษาและเกี่ยวกับแจ้งอยู่ในเมนูบัญชีที่มีอยู่แล้ว (`AccountButtonComponent` มี `about` และภาษา)
6. **ข้อความ hint ซ่อนเมื่อไม่ใช่สถานะ:** แสดงเฉพาะ `map.hint.allOff` กับ `map.hint.none` ส่วนข้อความแนะนำการซูม (`country`/`zooming`/`street`/`neighbourhood`) ยังอยู่ใน DOM เป็น `aria-live` แต่ซ่อนด้วย `.sr-only` (เจ้าของบอกว่า tip เยอะแล้วรก)
7. **3 เรื่องเด่นในแผงซ้าย:** จากข้อมูลที่โหลดมาแล้ว (`result.data.features`) ไม่ยิง API เพิ่ม เรียง: ยังไม่ปิด (`open`, `fix_claimed`) ก่อน → ระดับสูงก่อน → `confirm_count` มากก่อน → `days_open` มากก่อน
8. **จอกว้างตอนแผงรายละเอียดเปิด:** ถ้าจอกว้างไม่ถึง 1180 px แผงซ้ายยุบเหลือแถวค้นหาอย่างเดียว (ซ่อนชิปถึงลิงก์ "ดูทั้งหมด") เพื่อให้แผนที่ยังกว้างอย่างน้อย ~440 px
